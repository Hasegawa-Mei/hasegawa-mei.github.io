MODELING STANDARD

从原型到可替换模型

网页已完成

十个程序生成的三维方案，各有三种状态；支持旋转、缩放、状态对比和当前模型 GLB 导出。三视图来自同一组原型的正交投影，展示核心物件，不含场景底台。

混元 3D 适合接手

人物的自然衣褶与手部、树与花丛、音箱织物细节、软硅胶、箱壳曲面和幕布褶皱。结构明确的底座、盒体、卡片、接口、动画部件继续使用可控的几何建模。

交付与分件要求

统一 +Y 向上、+Z 向前；尺寸以米交付。一个物件一个独立文件；活动部件分网格，铰链处设原点。优先 GLB / glTF 2.0，PBR 材质，不烘焙地面阴影，不合并人物和座椅。

建议性能预算

每件主产品约 5,000–30,000 三角面，人物单体约 3,000–8,000；纹理优先 1K，主物件最多 2K。目标值需按最终设备实测，不视为性能承诺。玻璃薄壳单独分件，控制透明叠层。

本册提供形式提案与建模起点，不提供投产、结构、声学或安全认证。原型为叙事比例；正式模型需依据建议尺寸重新校准。三视图中的透明件用淡蓝表示，活动部件必须独立建模。

01 / POWER / 思辨产品设计

权力 — 关系长椅

哲学概念

权力产生于人们共同言说、共同行动之中。它依赖持续的共同参与，不能像物品一样被个人占有。

设计问题

公共座椅是在保护个人边界，还是替人决定彼此的距离？

产品 / 系统提案

一张可改变座面和中央扶手的公园长椅。隔断、向心座面和双方共同启用的照明，揭示空间对行为的安排，以及自愿协作与被动靠近的区别。

人与制度

双方各有一次启动权；任一人可以退出。移动部件仅在演示中自动切换。

靠近不等于共同行动。扶手与斜面是行为引导，不能直接叫作“权力增强／消失”。M 形座面是思辨演示，真实产品需要防滑、夹伤和人体工学验证。

01 / 划定边界

中央扶手划出各自的位置。边界清楚，也降低了交流的可能。

02 / 引导靠近

扶手升起消失；M 形座面的中央低谷引导两人滑向中间。距离变近，选择却未必更多。

03 / 共同启动

恢复平座面。两人共同选择启用一盏共享灯，关系由共同参与建立。

02 / PLURALITY / 声音产品设计

复数性 — 多声部音箱

哲学概念

人们既能够相互理解，又各自独特。复数性包含平等与差异；公共生活依赖不同的人在场，而非让所有人变得一样。

设计问题

共享声音必须被混成一个统一的声部吗？

产品 / 系统提案

三个可转向、独立控制的声学单元共用一座底盘。每位参与者保留自己的声源与停止权；转向聆听、轮流回应和并置播放，让差异可被分辨，而非自动混成“最佳和声”。

人与制度

声源由参与者各自控制；可退出、可拒绝混音；不以音量表示意见的价值。

多种声音只是复数性的感官入口，不等于人的政治平等。网页展示声源关系与转向机制，不提供真实声学性能模拟。

01 / 统一输出

三个单元同向，暴露单一广播逻辑。

02 / 独立声部

声源分别朝向不同的人，每个声部保留自己的位置。

03 / 轮流回应

单元转向彼此，轮流回应；不同意见没有被合成为一个答案。

03 / FABRICATION / 耐用品设计

制造 — 可修复旅行箱

哲学概念

制造以目的与材料为中介，做出相对持久的物件。这些物件构成人工世界的稳定性，与维持生命的循环活动形成区别。

设计问题

一只坏掉的轮子，为什么常常意味着丢掉整只箱子？

产品 / 系统提案

将箱壳、滚轮、拉杆和边角保护件分为可独立替换的单元。紧固点可见，内部保留简洁维修记录，新的部件和旧的表面共同延长同一件物品的生命。

人与制度

开放备件规格；可本地维修；保留维修历史；不把整箱替换作为默认方案。

重点不是模块化造型的趣味，而是持久物如何构成稳定的人工世界。强度、防水与耐久性能需进一步工程验证。

01 / 看见构造

箱壳、滚轮和拉杆分离，可读出连接关系。

02 / 继续旅行

部件装配为同一件持续使用的物品。

03 / 只换坏的部分

一个滚轮被替换，箱体与使用痕迹被保留。

04 / LABOR / 随身产品 × 服务系统

劳动 — 照护接力环

哲学概念

劳动对应维持生命的循环活动：需要不断出现，活动也必须反复进行。它的价值与必要性，不取决于是否留下永久成果。

设计问题

反复发生的备餐、清洁与补给，怎样被看见并被真正交接？

产品 / 系统提案

一组无排名的随身任务环与共享底座。环标记当前一轮维生活动；只有对方确认接手，任务才完成交接。完成后回到下一轮，让持续付出可见，也允许拒绝与重新协商。

人与制度

接手需双方确认；允许拒绝和调整；记录任务不排名个人；默认不上传个人数据。

照护不只有维持生命的劳动，也包含情感与关系。本设计仅处理可明确交接的重复任务，不用积分衡量关心，也不监测身体或医疗状态。

01 / 看见这一轮

一个环承接当前任务，其他环仍然空闲。

02 / 双方确认交接

任务经过共享底座交给另一人，不以单方分配替代同意。

03 / 下一轮继续

上一轮结束，新的需求出现；循环不会被一次完成永久消除。

05 / COMMON WORLD / 档案产品 × 公共保管系统

共同世界 — 传代档案盒

哲学概念

共同世界是我们从不同位置共同面对的事物与关系。它连接人，也把人区分开，使不同的人能够围绕同一件事物相遇。

设计问题

共同的记录，如何越过一次讨论和一代使用者？

产品 / 系统提案

一个无屏幕的公共档案盒，收藏街区设施、约定与争议的纸质记录。抽取式档案片可被共同阅读，保管人与续写者轮换，旧记录保留而非被新意见覆盖。

人与制度

由共同保管人轮值；公开阅读时间；争议记录并置；隐私信息需征得当事人同意。

私人纪念并不等于共同世界。这里的档案面向多人，保存共同事务，也容纳对同一事件的不同记述。

01 / 封存与保管

记录被可靠保存，但盒子仍需要公共的可访问规则。

02 / 共同阅读

盒盖打开，不同档案片并置，成为大家共同面对的对象。

03 / 后来者续写

一片新的记录加入，旧记录保留，世界不从零开始。

06 / NATALITY / 开放产品系统

诞生性 — 后来者的积木

哲学概念

诞生性指向每个新来者开始新事物的能力。新开端不只是旧程序的继续，也可能改变我们共同生活的方式。

设计问题

新来的人，是填入预设位置，还是能发起新的共同活动？

产品 / 系统提案

一组留有开放接口的共玩模块。新参与者可以带入不同形状的连接件，并提议改变规则；旧构件为新的连接移动，而不是要求新人适配唯一的标准答案。

人与制度

新参与者有发起权；旧规则可被质疑；玩法共同商议；儿童使用须另做小零件与材料验证。

单纯造型组合更接近创造与制造。这里强调新来者有权发起之前没有被安排的共同玩法，而不只是拼出新形状。

01 / 既有秩序

模块构成稳定的旧结构，但保留一个开放位置。

02 / 新来者加入

一个此前没有的连接件进入，原结构为它重新安排。

03 / 开始新玩法

连接发生改变；新的共同活动由参与者商议，而非产品预设。

07 / THOUGHT / 思辨产品设计

思考 — 停一拍终端

哲学概念

思考可以理解为人与自身展开的无声对话。它打断习惯和陈词滥调，让人重新审视自己正在做的事。

设计问题

当系统让“照常执行”越来越容易，设计能否保留一次停顿？

产品 / 系统提案

一台桌面审批装置，默认连续盖章；拨动暂停环后，印章抬起，镜面转向操作者，露出“为什么、谁受影响、我是否同意”三张提示片。

人与制度

暂停不能被后台自动取消；明确操作者责任；不宣称装置能作出正确判断。

思考不保证正确答案，也不是防止恶行的按钮。这个装置提出问题，不替操作者作出道德判断。

01 / 自动执行

印章重复运动，动作与结果被习惯连接。

02 / 暂停一下

印章停住，镜面转向操作者。

03 / 重新审视

三张提示片展开；下一步需要本人判断。

08 / PUBLIC REALM / 空间设计

公共领域 — 展开式议事幕

哲学概念

公共领域是人们通过言说和行动向彼此显现、讨论共同事务的空间。它不仅是一个地点，也依赖真实的公共参与。

设计问题

如何在日常场地中，临时建立可看见与可回应的讨论空间？

产品 / 系统提案

三片可折叠的半透明议事幕，把休息角转换为开放的讨论空间。展开后保留多个平整入口，低位座席相互可见；一片共享议题面与轮流发言机制一起工作。

人与制度

议题开放征集；轮流主持；不设唯一的高位讲台；无障碍与疏散需现场校核。

透明与开放不自动等于公共性。公共领域仍依赖平等参与、言说、回应与行动。

01 / 围合休息

幕片收拢，提供短暂的个人停留空间。

02 / 展开空间

幕片向外打开，留下平整入口与相互可见的座位。

03 / 开始讨论

共享议题面亮起，参与者轮流发言，也可以不同意。

09 / ACTION / 公共产品 × 参与系统

行动 — 公共提案邮筒

哲学概念

行动发生在人与人的关系之中。一个人可以发起开端，却无法独自控制他人的回应和最终结果。

设计问题

如何让一封提议进入公开的回应，而不止落入收件箱？

产品 / 系统提案

邮筒包含投入、公开回应和行动记录三个分区。提案公开后，参与者可以回应、修改或提出另一方向；可抽取卡片让意见走向讨论，空白槽持续接收新的发起。

人与制度

公布回应期限和负责者；允许修订与撤回；不只展示赞成意见；按实际进展记录。

投信本身不等于政治行动。系统必须包含真实的回应、共同发起和可能失败的后续，不能预设成功。

01 / 提出一件事

一张提案进入邮筒，尚未获得回应。

02 / 开放回应

回应窗口打开，参与、修改与分歧并置出现。

03 / 走向行动

一组卡片被共同取出继续讨论，仍留有未确定的空位。

10 / FREEDOM / 公共服务系统设计

自由 — 空白时段

哲学概念

自由在公共行动中显现：人能够与他人一起开始某件事。它不只是内在感受，也不等同于在既有菜单中选择。

设计问题

公共空间是否只允许人预约已经被规定好的活动？

产品 / 系统提案

为公共空间保留尚未命名的时段，配合可携带的发起牌、协作征集和可撤回的试行规则。参与者可以提出新的共同事务，而不是只能从课程菜单里消费一种选项。

人与制度

公开发起条件；无先到者永久占有；共同协商资源；获场地许可后试行；记录排斥与退出情况。

空闲时间不自动等于自由。这里借服务系统讨论共同发起的可能性；实际使用仍需要平等准入、共同规则与场地授权。

01 / 被安排的日程

日程牌已被填满，使用者只能从既定选项中挑选。

02 / 留出空白

一个时段被留出，尚未由管理者预定用途。

03 / 共同发起

新的发起牌进入，协作者参与决定内容，并保留撤回和修订。
