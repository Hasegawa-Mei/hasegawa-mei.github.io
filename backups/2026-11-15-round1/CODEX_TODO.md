# 留给 Codex 的后续工作

本清单用于 Claude 做视觉美化时记录复杂交互、底层调整和待正式验证事项。当前仅完成项目交接文档，尚未开展本轮美化，暂无实际移交条目。不要把模板当作已经发现的缺陷，也不要为填满清单主动开展测试或代码审计。

## 分工原则

简单、局部的 UI 交互由 Claude 直接完成。涉及多模块联动、共享状态、数据格式、规则、较大重构或反复排障的工作，在此记录后交回 Codex。Claude 继续完成不依赖这些事项的视觉工作。

预留时保留现有可用行为，以接口说明、设计状态、文件位置或简短接入注释表达需要接续的部分。不要留下假实现、无效按钮或中断现有流程的半成品。

## 每项记录模板

复制以下结构填写。只记录已知信息，不为补齐字段做额外调查。

### CX 编号与事项名称

- **用户目标**：想让页面最终呈现什么、操作后应该发生什么。
- **当前表现与触发方式**：在哪个页面、做了什么、看到什么；若是新需求，明确标注为新需求。
- **相关文件与定位**：相对项目根目录的路径，尽可能附函数名、选择器或组件区域；行号只作参考。
- **Claude 已完成**：具体视觉、布局、素材或简单交互修改。
- **交回原因**：需要跨哪些模块、改变什么状态或规则，为什么已超出简单 UI 工作。
- **预留与接口约定**：保留了哪个入口、现有调用、设计状态或注释；需要接入的输入、输出、事件或数据字段。
- **Codex 需完成**：实现、修复及必要验证的具体范围。
- **完成标准**：用户实际操作时应得到的结果。
- **关联资料**：截图或设计稿路径、观察到的错误原文；没有则省略。
- **影响与优先级**：是否阻碍本轮美化或正常使用，哪些独立工作仍可继续。
